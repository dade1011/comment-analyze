## Comment-Analyze
댓글에 대한 감정 분석을 수행한 후, 부정적으로 분류된 댓글을 분석하여 악성 댓글인지 여부를 판단

## How to use
1. stage1, stage2 모델이 모두 준비되고 "댓글 입력 >> "문구가 뜨면 원하는 문구를 입력 후 enter
2. 해당 문구의 악플 여부를 분석 및 출력
3. 또 다른 문구를 입력하거나 "exit"를 입력하여 종료

## 주의사항
git lfs 처리되어 있어 git clone 저장소주소로 땡겨와야 제대로 모델 파일을 가져올 수 있습니다.
